# 📊 SQL Portfolio – PostgreSQL | MySQL | Oracle

Este repositório foi criado com o objetivo de servir como **portfólio de estudos e práticas em SQL**, reunindo scripts desenvolvidos para diferentes bancos de dados relacionais, como **PostgreSQL, MySQL e Oracle**.

Os arquivos aqui apresentados abordam desde comandos básicos até consultas mais avançadas, com foco em **modelagem de dados, consultas eficientes, análise de informações e boas práticas em SQL**.

---

## 🎯 Objetivo do Repositório

- Consolidar o aprendizado prático em SQL  
- Demonstrar conhecimento em diferentes SGBDs  
- Servir como portfólio técnico para processos seletivos  
- Praticar consultas utilizadas no dia a dia profissional  

---

## 🛠️ Bancos de Dados Utilizados

Os scripts estão organizados por banco de dados:

- **PostgreSQL**
- **MySQL**
- **Oracle Database**

Cada pasta contém arquivos compatíveis com o respectivo SGBD.

---

## 📂 Estrutura do Repositório


> A estrutura pode evoluir conforme novos estudos e projetos forem adicionados.

## 📚 Conteúdos Abordados

Entre os principais temas trabalhados nos scripts estão:

- Criação de tabelas e relacionamentos  
- Inserção, atualização e exclusão de dados  
- Consultas com `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`  
- `JOINs` (INNER, LEFT, RIGHT)  
- Subqueries  
- Views  
- Functions e Procedures  
- Triggers  
- Otimização básica de consultas  

---

## ▶️ Como Utilizar

1. Escolha o banco de dados desejado  
2. Acesse a pasta correspondente  
3. Execute os scripts em um ambiente compatível (ex: pgAdmin, MySQL Workbench, SQL Developer, VS Code, etc.)
